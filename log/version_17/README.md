# Version 17 observed results — Pmax transfer sweep

This is a retrospective record of the completed V17 run. The frozen protocol
is `runs/PX17/PX00_protocol.json`; it binds the V15.2 lock, source pools,
previous natural samples, held-out complements, four Pmax levels and code
hashes before timing. `reports/KET_QUA_V17_PMAX.zip` is the official 45-file
bundle generated by the supplied runner and mirrored under `runs/`.

| Checkpoint | Result |
|---|---|
| CK0 | C self-test 216/216; unit tests 38/38; V15.2 lock reusable unchanged |
| CK1 | Protocol and all bound inputs verified; no problems |
| CK2 | Eight runs `DONE`; correct data and Pmax; X1 true in every run |
| CK3 | No missing run; 30, 35, 46 and 49 dBm all `TRANSFER_OK` |

Each run checked 2,700 compiled decisions against the Python oracle. Across
all eight runs there were 21,600 checked decisions, zero numeric events and
zero single/double decision changes.

| Deployment | Pmax (dBm) | R groups | Mean saving at K=8 (all groups) |
|---|---:|---:|---:|
| UMi | 30 | 0/100 | −0.07% |
| UMi | 35 | 0/100 | 0.08% |
| UMi | 46 | 0/100 | −0.04% |
| UMi | 49 | 0/100 | −0.03% |
| UMa | 30 | 100/100 | 97.05% |
| UMa | 35 | 99/100 | 93.04% |
| UMa | 46 | 71/100 | 53.67% |
| UMa | 49 | 56/100 | 39.28% |

UMi returned `INCONCLUSIVE_REGION_TOO_SMALL` in the per-run compiled report
because no group entered R. This is not a transfer failure: X5 is conditional
on at least five R groups. UMi still passed X1, X3 and X6; its worst lower
confidence bound outside R was about −1.3%, within the frozen −2% no-harm
limit. X4 is report-only and was not required for `TRANSFER_OK`.

UMa showed large savings, while R prevalence and savings fell as Pmax rose.
At 30 and 35 dBm there were fewer than five groups outside R, so X6 was not
evaluable; at 46 and 49 dBm both X5 and X6 passed. The maximum observed
single/double relative power difference was about 0.58% on UMi at 49 dBm,
but it changed no decision and did not trigger a numeric event.

Scope: deterministic held-out complements of the two existing 200-group
natural pools, finite ZF/RZF candidate family, compiled timing on the same
machine, and the four tested Pmax levels. The result supports safe transfer
of the frozen map under these conditions. It does not establish positive
speedup on UMi, unrestricted beamforming optimality, production readiness,
or a guarantee for other channel distributions and power levels.

Real NPZ files and per-geometry task caches remain outside Git. The protocol
and manifests retain their SHA-256 identities. `ARTIFACT_SHA256.csv` hashes
all curated artifacts stored in this directory.
